# Telegram-бот: цены на Ozon

Бот по запросу показывает текущую цену товара Ozon. Раз в сутки сам
обновляет сохранённые цены (чтобы `/list` не показывал совсем старые
данные), но никого не уведомляет сам — только отвечает на команды.

## Установка

```bash
cd ozon_price_bot
python3 -m venv venv
source venv/bin/activate        # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium   # один раз, для рендеринга страниц Ozon
```

## Токен бота

1. Напишите @BotFather в Telegram, создайте бота командой `/newbot`.
2. Скопируйте выданный токен.
3. Задайте переменную окружения перед запуском:

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
```

## Запуск

```bash
python bot.py
```

## Добавление товаров

Самый простой способ — **просто прислать боту ссылку на товар** обычным
сообщением, без команды. Бот сам распознает ссылку на ozon.ru, проверит
цену и добавит товар. Можно прислать и несколько ссылок в одном
сообщении — добавит все.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | приветствие и список команд |
| `/add <ссылка>` | добавить товар тем же способом, но явной командой |
| `/list` | список товаров и последняя известная цена |
| `/price <id>` | проверить АКТУАЛЬНУЮ цену прямо сейчас |
| `/history <id>` | история изменения цены (каждая проверка сохраняется) |
| `/remove <id>` | удалить товар из списка |

`id` — номер товара, который показывается в `/list`.

## Важные оговорки

- **Ozon активно защищается от ботов** и периодически меняет вёрстку
  страниц. Код сначала пытается получить цену из сырого HTML (быстро),
  а если не получилось — рендерит страницу настоящим браузером
  (Playwright). Оба способа могут со временем перестать работать —
  тогда нужно будет открыть страницу товара, посмотреть текущую
  разметку ("Просмотр кода страницы" / DevTools) и поправить
  селекторы/регулярные выражения в `scraper.py`.
- Слишком частые автоматические запросы к сайту могут приводить к
  временной блокировке по IP — поэтому стоит не делать проверки чаще,
  чем реально нужно, и имеет смысл свериться с пользовательским
  соглашением Ozon насчёт автоматизированного доступа к сайту.
- Хранилище — простой файл `tracked_items.db` (SQLite) рядом с ботом.
  Для продакшена на отдельном сервере рекомендуется регулярно делать
  его резервную копию.
- Бот сейчас хранит товары отдельно для каждого пользователя Telegram
  (`user_id`), так что разные люди не увидят списки друг друга.

## Деплой на Railway.app (круглосуточно, без своего компьютера)

1. Загрузите все файлы бота в репозиторий на GitHub.
2. На [railway.app](https://railway.app) войдите через GitHub аккаунт.
3. New Project → Deploy from GitHub repo → выберите репозиторий.
4. В настройках проекта (Variables) добавьте переменную
   `TELEGRAM_BOT_TOKEN` со значением токена от @BotFather.
5. Railway найдёт `nixpacks.toml` и `requirements.txt` и соберёт проект
   сам — зависимости и браузер Chromium поставятся автоматически.
6. После сборки бот запустится и будет работать постоянно. Логи видно
   во вкладке Deployments → View Logs.

Файл базы данных `tracked_items.db` на бесплатном тарифе хранится на
диске контейнера: при каждом новом деплое (например, после правки кода)
он может обнуляться. Если это важно, в Railway можно подключить Volume
(Settings → Volumes) и указать в `storage.py` путь к файлу внутри него.

## Возможные доработки

- Уведомления при снижении цены (сейчас по вашему запросу — только
  показ цены по команде).
- Поддержка других магазинов (Wildberries, Avito и т.д.) — потребует
  отдельного парсера под структуру конкретного сайта.
- График динамики цены (сейчас `/history` показывает текст, можно
  добавить картинку-график).
